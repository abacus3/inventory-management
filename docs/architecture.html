Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app talks over HTTP/JSON to a FastAPI service. The service serves sample data from JSON files that it loads into memory at startup. There is no database.

System architecture

  • Axios

Data flow: a filtered request

  1. The user changes a filter in FilterBar: Time Period, Warehouse, Category, or Order Status.
  2. useFilters holds the filter state in module-level refs, so every view shares one copy. getCurrentFilters() turns the period into a month value.
  3. The view's watcher calls api.js, which sends GET /api/orders?warehouse=…&category=…&status=…&month=….
  4. FastAPI runs apply_filters() (exact warehouse match, case-insensitive category and status), then filter_by_month() (substring match on order_date, with Q1–Q4 expanded to their months).
  5. The response is checked against its Pydantic response_model and returned as JSON.
  6. The view stores the raw data in refs such as allOrders and inventoryItems. Totals, chart series, and table rows are computed properties derived from those refs.

Things to know

Client calls with no server route. api.js calls /api/tasks (GET, POST, PATCH, DELETE), POST /api/purchase-orders and GET /api/purchase-orders/{id}, but main.py defines none of these routes, so those requests get a 404.

Inventory has no time dimension, so the month filter doesn't apply to it. views/Backlog.vue exists but isn't registered in the router.
